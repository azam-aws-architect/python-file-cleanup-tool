🚀 Built a Smart File Organizer script in Python to automatically clean up messy directories and keep local environments organized!

Instead of sorting files manually, this script automatically categorizes everything in your Downloads folder into designated folders (Images, Documents, Archives, Code, and Setup Files), handles duplicate file names safely without overwriting, and generates a clean cleanup_report.txt summary breakdown.

Key Features:

Automatic extension-based sorting

Safe unique path generation for duplicate files

Live category-wise breakdown and automated logging

Simple, efficient, and zero external dependencies needed.
